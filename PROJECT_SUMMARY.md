## 🚀 What You Can Do Now

### Immediate Next Steps

1. **Install Dependencies**
   ```bash
   cd vinr-docs-monorepo
   pnpm install
   ```

2. **Start Development**
   ```bash
   pnpm dev
   ```
   - docs: http://localhost:3000
   - support: http://localhost:3001

3. **View Sample Content**
   - Navigate to http://localhost:3000/merchant
   - Click "Get Started"
   - Check out the Quick Start guide with code examples
