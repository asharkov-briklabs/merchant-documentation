## List all customers

Returns a list of your customers.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/customers"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false},{"name":"ending_before","type":"string","defaultValue":"","isRequired":false},{"name":"email","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

<Property name={"ending_before"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `ending_before` is an object ID that defines your place in the list.

</Property>

<Property name={"email"} type={"string"} required={false} deprecated={false}>

A case-sensitive filter on the list based on the customer's email field.

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | A dictionary with a `data` property that contains an array of customers. |

</APIInfo>
