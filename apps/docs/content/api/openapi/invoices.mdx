## List all invoices

You can list all invoices, or list the invoices for a specific customer.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/invoices"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false},{"name":"ending_before","type":"string","defaultValue":"","isRequired":false},{"name":"customer","type":"string","defaultValue":"","isRequired":false},{"name":"subscription","type":"string","defaultValue":"","isRequired":false},{"name":"status","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

<Property name={"ending_before"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `ending_before` is an object ID that defines your place in the list.

</Property>

<Property name={"customer"} type={"string"} required={false} deprecated={false}>

Only return invoices for the customer specified by this customer ID.

</Property>

<Property name={"subscription"} type={"string"} required={false} deprecated={false}>

Only return invoices for the subscription specified by this subscription ID.

</Property>

<Property name={"status"} type={"string"} required={false} deprecated={false}>

The status of the invoice, one of `draft`, `open`, `paid`, `uncollectible`, or `void`.

<span>Value in: `"draft" | "open" | "paid" | "uncollectible" | "void"`</span>

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a list of invoice objects. |

</APIInfo>

## Create an invoice

This endpoint creates a draft invoice for a given customer. The draft invoice created pulls in all pending invoice items on that customer.

### Request Body

</Property>

<Property name={"auto_advance"} type={"boolean"} required={false} deprecated={undefined}>

<span>Default: `true`</span>

</Property>

<Property name={"collection_method"} type={"string"} required={false} deprecated={undefined}>

<span>Default: `"charge_automatically"`</span>

<span>Value in: `"charge_automatically" | "send_invoice"`</span>

</Property>

<Property name={"days_until_due"} type={"integer"} required={false} deprecated={undefined}>

Number of days a customer has to pay the invoice, if `collection_method` is `send_invoice`.

</Property>
