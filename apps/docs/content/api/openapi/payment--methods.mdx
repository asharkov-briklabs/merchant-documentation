## List payment methods

Returns a list of payment methods attached to the customer specified.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/payment-methods"} bodyType={"json"} path={[]} query={[{"name":"customer","type":"string","defaultValue":"","isRequired":true},{"name":"type","type":"string","defaultValue":"","isRequired":false},{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"customer"} type={"string"} required={true} deprecated={false}>

The ID of the customer whose payment methods will be retrieved.

</Property>

<Property name={"type"} type={"string"} required={false} deprecated={false}>

An optional filter on the list, based on the object `type` field.

<span>Value in: `"card" | "sepa_debit" | "us_bank_account"`</span>

</Property>

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | A dictionary with a `data` property that contains an array of payment methods. |

</APIInfo>

## Create a payment method

Creates a new payment method object. Payment methods allow you to collect payment information from a customer.

</APIPlayground>

### Authorization

In: `header`

</Property>

### Request Body

<Property name={"type"} type={"string"} required={true} deprecated={undefined}>

The type of the payment method.

<span>Value in: `"card" | "sepa_debit" | "us_bank_account"`</span>

</Property>

<Property name={"card"} type={"object"} required={false} deprecated={undefined}>

If this is a card payment method, this field contains card details.

<ObjectCollapsible name={"card"}>

<Property name={"number"} type={"string"} required={false} deprecated={undefined}>

The card number, as a string without any separators.

<span>Example: `"4242424242424242"`</span>

</Property>

<Property name={"exp_month"} type={"integer"} required={false} deprecated={undefined}>

Two-digit number representing the card's expiration month.

<span>Example: `12`</span>

</Property>

<Property name={"exp_year"} type={"integer"} required={false} deprecated={undefined}>

Four-digit number representing the card's expiration year.

<span>Example: `2026`</span>

</Property>

<Property name={"cvc"} type={"string"} required={false} deprecated={undefined}>

Card security code.

<span>Example: `"314"`</span>

</Property>

</ObjectCollapsible>

</Property>

<Property name={"billing_details"} type={"object"} required={false} deprecated={undefined}>

<ObjectCollapsible name={"billing_details"}>

</Property>

</Property>

<Property name={"phone"} type={"string"} required={false} deprecated={undefined}>

</Property>

</ObjectCollapsible>

</Property>

| `200` | Returns a payment method object. |
