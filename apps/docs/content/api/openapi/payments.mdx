## List all payments

Returns a list of payments. Payments are sorted by creation date, with the most recent payments appearing first.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/payments"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false},{"name":"ending_before","type":"string","defaultValue":"","isRequired":false},{"name":"customer","type":"string","defaultValue":"","isRequired":false},{"name":"created","type":"number","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

<Property name={"ending_before"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `ending_before` is an object ID that defines your place in the list.

</Property>

<Property name={"customer"} type={"string"} required={false} deprecated={false}>

Only return payments for the customer specified by this customer ID.

</Property>

<Property name={"created"} type={"integer"} required={false} deprecated={false}>

Only return payments created during the given date interval (Unix timestamp).

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | A dictionary with a `data` property that contains an array of payments. |

</APIInfo>

## Create a payment

Creates a new payment object. To be used when you intend to create a payment and accept
payment in a single call. If you want to authorize and capture payment separately, set
`capture_method` to `manual`.

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

</Property>

### Request Body

<Property name={"amount"} type={"integer"} required={true} deprecated={undefined}>

Amount intended to be collected by this payment, in the smallest currency unit.

<span>Example: `2000`</span>

</Property>

<Property name={"currency"} type={"string"} required={true} deprecated={undefined}>

Three-letter ISO currency code, in lowercase.

<span>Example: `"usd"`</span>

</Property>

<Property name={"customer"} type={"string"} required={false} deprecated={undefined}>

ID of the customer this payment is intended for, if one exists.

</Property>

<Property name={"payment_method"} type={"string"} required={false} deprecated={undefined}>

ID of the payment method to attach to this payment.

</Property>

<Property name={"capture_method"} type={"string"} required={false} deprecated={undefined}>

Controls when the funds will be captured.

<span>Default: `"automatic"`</span>

<span>Value in: `"automatic" | "manual"`</span>

</Property>

<Property name={"description"} type={"string"} required={false} deprecated={undefined}>

An arbitrary string attached to the object. Often useful for displaying to users.

</Property>

<Property name={"metadata"} type={"object"} required={false} deprecated={undefined}>

Set of key-value pairs for storing additional structured information.

<ObjectCollapsible name={"metadata"}>

<Property name={"[key: string]"} type={"string"} required={false} deprecated={undefined}>

</Property>

</ObjectCollapsible>

</Property>

<Property name={"receipt_email"} type={"string"} required={false} deprecated={undefined}>

Email address that the receipt for the resulting payment will be sent to.

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a payment object. |
| `400` | Bad request. |
| `401` | No valid API key provided. |

</APIInfo>

## Capture a payment

Capture the funds of an existing uncaptured payment created with `capture_method: manual`.
You can only capture up to the amount of the original payment. Pass an `amount_to_capture`
to capture less than the full amount.

## Cancel a payment

authorization and does not trigger any application fee refunds.
