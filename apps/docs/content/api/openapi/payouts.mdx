## List all payouts

Returns a list of existing payouts sent to third-party bank accounts or that Vinr has sent you.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/payouts"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false},{"name":"ending_before","type":"string","defaultValue":"","isRequired":false},{"name":"status","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

<Property name={"ending_before"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `ending_before` is an object ID that defines your place in the list.

</Property>

<Property name={"status"} type={"string"} required={false} deprecated={false}>

Only return payouts that have the given status.

<span>Value in: `"paid" | "pending" | "in_transit" | "canceled" | "failed"`</span>

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a list of payout objects. |

</APIInfo>

## Create a payout

To send funds to your own bank account, you create a new payout object.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"POST"} route={"/payouts"} bodyType={"json"} path={[]} query={[]} header={[]} body={{"type":"object","isRequired":true,"properties":{"amount":{"type":"ref","isRequired":true,"schema":"0"},"currency":{"type":"ref","isRequired":true,"schema":"1"},"method":{"type":"ref","isRequired":false,"schema":"2"},"description":{"type":"ref","isRequired":false,"schema":"3"},"metadata":{"type":"ref","isRequired":false,"schema":"4"}}}} schemas={{"0":{"type":"number","defaultValue":"","isRequired":false,"description":"A positive integer representing how much to pay out in the smallest currency unit."},"1":{"type":"string","defaultValue":"","isRequired":false,"description":"Three-letter ISO currency code, in lowercase."},"2":{"type":"string","defaultValue":"","isRequired":false,"description":"The method used to send this payout. `instant` is only supported for payouts to debit cards."},"3":{"type":"string","defaultValue":"","isRequired":false},"4":{"type":"object","isRequired":false,"properties":{},"additionalProperties":"5"},"5":{"type":"string","defaultValue":"","isRequired":false}}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Request Body

<Property name={"amount"} type={"integer"} required={true} deprecated={undefined}>

A positive integer representing how much to pay out in the smallest currency unit.

</Property>

<Property name={"currency"} type={"string"} required={true} deprecated={undefined}>

Three-letter ISO currency code, in lowercase.

</Property>

<Property name={"method"} type={"string"} required={false} deprecated={undefined}>

The method used to send this payout. `instant` is only supported for payouts to debit cards.

<span>Default: `"standard"`</span>

<span>Value in: `"standard" | "instant"`</span>

</Property>

<Property name={"description"} type={"string"} required={false} deprecated={undefined}>

</Property>

<Property name={"metadata"} type={"object"} required={false} deprecated={undefined}>

<ObjectCollapsible name={"metadata"}>

<Property name={"[key: string]"} type={"string"} required={false} deprecated={undefined}>

</Property>

</ObjectCollapsible>

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a payout object. |

</APIInfo>
