## List all refunds

Returns a list of all refunds you've previously created.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/refunds"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false},{"name":"ending_before","type":"string","defaultValue":"","isRequired":false},{"name":"payment","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

<Property name={"ending_before"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `ending_before` is an object ID that defines your place in the list.

</Property>

<Property name={"payment"} type={"string"} required={false} deprecated={false}>

Only return refunds for the payment specified by this payment ID.

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a list of refund objects. |

</APIInfo>

## Create a refund

When you create a new refund, you must specify either a payment or a charge.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"POST"} route={"/refunds"} bodyType={"json"} path={[]} query={[]} header={[]} body={{"type":"object","isRequired":true,"properties":{"payment":{"type":"ref","isRequired":true,"schema":"0"},"amount":{"type":"ref","isRequired":false,"schema":"1"},"reason":{"type":"ref","isRequired":false,"schema":"2"},"metadata":{"type":"ref","isRequired":false,"schema":"3"}}}} schemas={{"0":{"type":"string","defaultValue":"","isRequired":false,"description":"The identifier of the payment to be refunded."},"1":{"type":"number","defaultValue":"","isRequired":false,"description":"A positive integer representing how much to refund. </APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Request Body

<Property name={"payment"} type={"string"} required={true} deprecated={undefined}>

The identifier of the payment to be refunded.

</Property>

<Property name={"amount"} type={"integer"} required={false} deprecated={undefined}>

A positive integer representing how much to refund. Defaults to the full amount of the payment.

</Property>

<Property name={"reason"} type={"string"} required={false} deprecated={undefined}>

The reason for the refund.

<span>Value in: `"duplicate" | "fraudulent" | "requested_by_customer"`</span>

</Property>

| ----------- | ----------- |
| `200` | Returns a refund object. |
