## List all subscriptions

By default, returns a list of subscriptions that have not been canceled.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/subscriptions"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false},{"name":"ending_before","type":"string","defaultValue":"","isRequired":false},{"name":"customer","type":"string","defaultValue":"","isRequired":false},{"name":"status","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

<Property name={"ending_before"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `ending_before` is an object ID that defines your place in the list.

</Property>

<Property name={"customer"} type={"string"} required={false} deprecated={false}>

The ID of the customer whose subscriptions will be retrieved.

</Property>

<Property name={"status"} type={"string"} required={false} deprecated={false}>

The status of the subscriptions to retrieve.

<span>Value in: `"active" | "past_due" | "canceled" | "unpaid" | "incomplete" | "incomplete_expired" | "trialing" | "all"`</span>

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a list of subscription objects. |

</APIInfo>

</Property>

### Request Body

<Property name={"customer"} type={"string"} required={true} deprecated={undefined}>

The identifier of the customer to subscribe.

</Property>

<Property name={"items"} type={"array<object>"} required={true} deprecated={undefined}>

A list of up to 20 subscription items, each with an attached price.

<ObjectCollapsible name={"Object 1"}>

The ID of the price to subscribe to.

</Property>

<span>Default: `1`</span>

</Property>

</ObjectCollapsible>

</Property>

<Property name={"trial_period_days"} type={"integer"} required={false} deprecated={undefined}>

Integer representing the number of trial period days before the customer is charged for the first time.

</Property>

<Property name={"cancel_at_period_end"} type={"boolean"} required={false} deprecated={undefined}>

Boolean indicating whether this subscription should cancel at the end of the current period.

<span>Default: `false`</span>

</Property>

<Property name={"default_payment_method"} type={"string"} required={false} deprecated={undefined}>

ID of the default payment method for the subscription.

</Property>

<Property name={"[key: string]"} type={"string"} required={false} deprecated={undefined}>

</Property>

| ----------- | ----------- |
