## List all webhook endpoints

Returns a list of your webhook endpoints.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"GET"} route={"/webhook-endpoints"} bodyType={"json"} path={[]} query={[{"name":"limit","type":"number","defaultValue":"","isRequired":false},{"name":"starting_after","type":"string","defaultValue":"","isRequired":false}]} header={[]} body={undefined} schemas={{}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Query Parameters

<Property name={"limit"} type={"integer"} required={false} deprecated={false}>

A limit on the number of objects to be returned, between 1 and 100.

<span>Default: `10`</span>

<span>Minimum: `1`</span>

<span>Maximum: `100`</span>

</Property>

<Property name={"starting_after"} type={"string"} required={false} deprecated={false}>

A cursor for use in pagination. `starting_after` is an object ID that defines your place in the list.

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns a list of webhook endpoint objects. |

</APIInfo>

## Create a webhook endpoint

A webhook endpoint must have a `url` and a list of `enabled_events`. You may optionally specify the Boolean `connect` parameter.

<APIPlayground authorization={{"type":"string","name":"Authorization","defaultValue":"Bearer","isRequired":true,"description":"The Authorization access token"}} method={"POST"} route={"/webhook-endpoints"} bodyType={"json"} path={[]} query={[]} header={[]} body={{"type":"object","isRequired":true,"properties":{"url":{"type":"ref","isRequired":true,"schema":"0"},"enabled_events":{"type":"ref","isRequired":true,"schema":"1"},"description":{"type":"ref","isRequired":false,"schema":"3"},"metadata":{"type":"ref","isRequired":false,"schema":"4"}}}} schemas={{"0":{"type":"string","defaultValue":"https://example.com/webhooks","isRequired":false,"description":"The URL of the webhook endpoint."},"1":{"type":"array","description":"The list of events to enable for this endpoint. Specify `['*']` to enable all events.","isRequired":false,"items":"2"},"2":{"type":"string","defaultValue":"","isRequired":false},"3":{"type":"string","defaultValue":"","isRequired":false,"description":"An optional description of what the webhook is used for."},"4":{"type":"object","isRequired":false,"properties":{},"additionalProperties":"5"},"5":{"type":"string","defaultValue":"","isRequired":false}}}>

</APIPlayground>

### Authorization

<Property name={"Authorization"} type={"Bearer <token>"} required={true}>

Use your secret API key (`sk_live_...` or `sk_test_...`) as a bearer token.

In: `header`

</Property>

### Request Body

<Property name={"url"} type={"string"} required={true} deprecated={undefined}>

The URL of the webhook endpoint.

<span>Example: `"https://example.com/webhooks"`</span>

</Property>

<Property name={"enabled_events"} type={"array<string>"} required={true} deprecated={undefined}>

The list of events to enable for this endpoint. Specify `['*']` to enable all events.

<span>Example: `["payment.succeeded","payment.failed"]`</span>

</Property>

<Property name={"description"} type={"string"} required={false} deprecated={undefined}>

An optional description of what the webhook is used for.

</Property>

<Property name={"metadata"} type={"object"} required={false} deprecated={undefined}>

<ObjectCollapsible name={"metadata"}>

<Property name={"[key: string]"} type={"string"} required={false} deprecated={undefined}>

</Property>

</ObjectCollapsible>

</Property>

| Status code | Description |
| ----------- | ----------- |
| `200` | Returns the webhook endpoint object. |

</APIInfo>
