## Overview

Vinr provides separate API credentials for sandbox and production environments.

## Credential Types

### Sandbox Credentials

Used for development and testing:

- **API Key**: `bk_sandbox_...`
- **API Secret**: Provided securely during onboarding
- **Webhook Secret**: For verifying webhook authenticity

### Production Credentials

Used for live transaction processing:

- **API Key**: `bk_live_...`
- **API Secret**: Provided securely during go-live
- **Webhook Secret**: For verifying webhook authenticity

## Receiving Credentials

### Sandbox Access

1. Complete initial onboarding application
2. Sign NDA and preliminary agreements
3. Receive sandbox credentials via secure channel
4. Access sandbox documentation

### Production Access

1. Complete all integration testing
2. Pass security and compliance reviews
3. Sign production agreements
4. Receive production credentials

## Security Requirements

### Credential Storage

- Store credentials in secure key management systems
- Never commit credentials to version control
- Rotate credentials according to security policy
- Use environment variables in applications

### Access Control

- Limit credential access to authorized personnel
- Implement role-based access control
- Maintain audit logs of credential usage
- Revoke access when personnel leave

## API Authentication

All API requests must include authentication:

```bash
curl https://api.vinr.com/v1/bank/transactions \
  -u bk_live_YOUR_API_KEY:YOUR_API_SECRET
```

Or using Bearer token:

```bash
curl https://api.vinr.com/v1/bank/transactions \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

## Credential Rotation

### Regular Rotation

Rotate credentials every 90 days:

1. Generate new credentials in dashboard
2. Update applications with new credentials
3. Verify functionality
4. Revoke old credentials

### Emergency Rotation

If credentials are compromised:

1. Immediately contact Vinr support
2. Credentials will be revoked within 15 minutes
3. New credentials issued
4. Update all systems urgently
