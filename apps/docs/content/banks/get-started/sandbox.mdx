## Overview

The sandbox environment is a complete replica of the production system for testing your integration.

## Sandbox Features

- Full API functionality
- Test payment instruments
- Webhook testing
- Error simulation
- No real money transactions

## Sandbox Endpoints

### API Base URL
```
https://api-sandbox.vinr.com/v1/bank
```

### Dashboard
```
https://dashboard-sandbox.vinr.com
```

## Testing Scenarios

### 1. Authorization

Test payment authorization:

```bash
curl https://api-sandbox.vinr.com/v1/bank/authorize \
  -u bk_sandbox_YOUR_KEY:YOUR_SECRET \
  -d merchant_id=merch_test_001 \
  -d amount=5000 \
  -d currency=EUR \
  -d card_number=4242424242424242
```

### 2. Capture

Test payment capture:

```bash
curl https://api-sandbox.vinr.com/v1/bank/capture \
  -u bk_sandbox_YOUR_KEY:YOUR_SECRET \
  -d authorization_id=auth_123456
```

### 3. Refund

Test refund processing:

```bash
curl https://api-sandbox.vinr.com/v1/bank/refund \
  -u bk_sandbox_YOUR_KEY:YOUR_SECRET \
  -d transaction_id=txn_123456 \
  -d amount=5000
```

### 4. Webhook Testing

Simulate webhook events:

```bash
curl https://api-sandbox.vinr.com/v1/bank/simulate-webhook \
  -u bk_sandbox_YOUR_KEY:YOUR_SECRET \
  -d event_type=transaction.completed \
  -d transaction_id=txn_123456
```

## Rate Limits

Sandbox has the same rate limits as production:

- 100 requests per second
- 10,000 requests per hour

## Data Retention

Sandbox data is retained for 30 days, then automatically deleted.

## Moving to Production

Before moving to production:

- [ ] Complete all test scenarios
- [ ] Verify webhook handling
- [ ] Test error recovery
- [ ] Validate settlement reconciliation
- [ ] Complete security review
- [ ] Document integration
