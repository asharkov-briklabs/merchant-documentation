## Overview

Settlement is the process of transferring funds from the bank to merchants for completed transactions.

## Settlement Schedule

### Daily Settlement

Settlements are processed daily:

- **Cut-off time**: 23:59 UTC
- **Settlement batch**: Created at 00:00 UTC
- **Funds transfer**: Within 2 business days

### Settlement Timing

| Day | Activity |
|-----|----------|
| T+0 | Transaction captured |
| T+1 | Settlement batch created |
| T+2 | Funds transferred to merchant |

## Settlement Batch API

### Get Settlement Batch

```
GET /v1/bank/settlements/{batch_id}
```

### Response

```json
{
  "batch_id": "batch_20240315",
  "settlement_date": "2024-03-15",
  "total_amount": 125000,
  "currency": "EUR",
  "transaction_count": 47,
  "status": "completed",
  "transactions": [
    {
      "transaction_id": "txn_abc123",
      "merchant_id": "merch_123",
      "amount": 5000,
      "fee": 150,
      "net_amount": 4850
    }
  ]
}
```

## Settlement Statuses

| Status | Description |
|--------|-------------|
| `pending` | Settlement batch being prepared |
| `processing` | Funds being transferred |
| `completed` | Settlement completed |
| `failed` | Settlement failed |

## Settlement Adjustments

### Create Adjustment

```
POST /v1/bank/settlement-adjustment
```

### Request

```json
{
  "batch_id": "batch_20240315",
  "merchant_id": "merch_123",
  "amount": -500,
  "reason": "chargeback",
  "reference": "cb_xyz789"
}
```

## Chargebacks

### Chargeback Notification

```
POST /v1/bank/chargeback
```

### Request

```json
{
  "transaction_id": "txn_abc123",
  "amount": 5000,
  "reason_code": "4853",
  "reason": "Cardholder Dispute",
  "received_date": "2024-03-15",
  "respond_by": "2024-03-30"
}
```
