## Overview

Webhooks provide real-time notifications about events in the Vinr platform.

## Webhook Events

### Transaction Events

- `transaction.authorized` - Payment authorized
- `transaction.captured` - Payment captured
- `transaction.failed` - Payment failed
- `transaction.voided` - Authorization voided

### Settlement Events

- `settlement.created` - Settlement batch created
- `settlement.completed` - Settlement completed
- `settlement.failed` - Settlement failed

### Refund Events

- `refund.created` - Refund initiated
- `refund.completed` - Refund completed
- `refund.failed` - Refund failed

### Chargeback Events

- `chargeback.created` - Chargeback received
- `chargeback.resolved` - Chargeback resolved

### Add Webhook Endpoint

```json
{
  "url": "https://your-bank.com/vinr/webhooks",
  "events": [
    "transaction.authorized",
    "transaction.captured",
    "settlement.created"
  ],
  "secret": "whsec_your_secret_key"
}
```

## Verifying Webhooks

Always verify webhook signatures:

```javascript
const crypto = require('crypto');

function verifyWebhook(payload, signature, secret) {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
  
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
}
```

## Webhook Handler Example

```javascript
app.post('/vinr/webhooks', (req, res) => {
  const signature = req.headers['vinr-signature'];
  const payload = JSON.stringify(req.body);
  
  if (!verifyWebhook(payload, signature, webhookSecret)) {
    return res.status(401).send('Invalid signature');
  }
  
  const event = req.body;
  
  switch (event.event_type) {
    case 'transaction.captured':
      handleTransactionCaptured(event.data);
      break;
    case 'settlement.created':
      handleSettlementCreated(event.data);
      break;
  }
  
  res.json({received: true});
});
```

## Retry Logic

If webhook delivery fails, Vinr will retry:

- Immediately
- After 5 minutes
- After 30 minutes
- After 2 hours
- After 6 hours
- After 24 hours

## Best Practices

- Respond quickly (within 5 seconds)
- Process webhooks asynchronously
- Verify signatures
- Handle duplicate events (idempotency)
- Log all webhook events
- Monitor webhook health
