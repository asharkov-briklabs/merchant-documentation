## Introduction

Vinr provides comprehensive reporting capabilities for bank partners to track transactions, settlements, and reconciliation.

## Report Types

### Transaction Reports

Detailed transaction data including authorizations, captures, and refunds.

### Settlement Reports

Daily settlement batches and fund transfer details.

### Reconciliation Reports

Tools to reconcile your records with Vinr's platform.

### Performance Reports

Analytics on transaction success rates, processing times, and more.

## Accessing Reports

### Dashboard

View and download reports from the [Bank Partner Dashboard](https://dashboard.vinr.com/bank).

### API

Retrieve reports programmatically via the Reporting API.

### Scheduled Delivery

Configure automatic report delivery via email or SFTP.

## Report Formats

- **CSV** - For spreadsheet import
- **JSON** - For programmatic processing
- **PDF** - For documentation and records
- **XML** - For legacy system integration

## Data Retention

- **Transaction data**: 7 years
- **Settlement data**: 7 years
- **Logs**: 1 year
- **Reports**: Available for download for 90 days

## Real-time Data

Access near real-time data via:

- Webhooks for instant notifications
- API polling (rate limited)
- Dashboard auto-refresh
