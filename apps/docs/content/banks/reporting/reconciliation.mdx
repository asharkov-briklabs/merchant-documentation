## Overview

Reconciliation tools help you verify that Vinr's records match your internal systems.

## Daily Reconciliation

### Get Daily Reconciliation Report

```
GET /v1/bank/reconciliation/daily?date=2024-03-15
```

### Response

```json
{
  "date": "2024-03-15",
  "summary": {
    "authorizations": {
      "count": 156,
      "approved": 142,
      "declined": 14,
      "total_amount": 456000
    },
    "captures": {
      "count": 138,
      "total_amount": 425000
    },
    "refunds": {
      "count": 5,
      "total_amount": 12500
    },
    "settlement": {
      "batch_id": "batch_20240315",
      "net_amount": 412500
    }
  },
  "discrepancies": []
}
```

## Transaction-Level Reconciliation

Compare individual transactions:

```
POST /v1/bank/reconciliation/verify
```

### Request

```json
{
  "date": "2024-03-15",
  "transactions": [
    {
      "your_reference": "bank_txn_123",
      "vinr_transaction_id": "txn_abc123",
      "amount": 5000,
      "status": "captured"
    }
  ]
}
```

### Response

```json
{
  "matched": 137,
  "unmatched": 1,
  "discrepancies": [
    {
      "your_reference": "bank_txn_456",
      "issue": "amount_mismatch",
      "your_amount": 5000,
      "vinr_amount": 5050
    }
  ]
}
```

## Settlement Reconciliation

Verify settlement amounts:

```
GET /v1/bank/reconciliation/settlement/{batch_id}
```

### Response

```json
{
  "batch_id": "batch_20240315",
  "settlement_date": "2024-03-15",
  "expected_amount": 425000,
  "fees": 12500,
  "net_amount": 412500,
  "transaction_breakdown": {
    "captures": 425000,
    "refunds": -12500,
    "chargebacks": 0,
    "adjustments": 0
  },
  "status": "reconciled"
}
```

## Discrepancy Resolution

### Report Discrepancy

```
POST /v1/bank/reconciliation/discrepancy
```

### Request

```json
{
  "transaction_id": "txn_abc123",
  "issue_type": "amount_mismatch",
  "description": "Amount differs by €0.50",
  "your_amount": 5000,
  "vinr_amount": 5050
}
```

## Automated Reconciliation

Set up automated daily reconciliation:

```
POST /v1/bank/reconciliation/automate
```

```json
{
  "enabled": true,
  "schedule": "daily",
  "time": "07:00",
  "notify_on_discrepancy": true,
  "email_recipients": ["reconciliation@your-bank.com"]
}
```

## Reconciliation File Format

Upload your reconciliation file (CSV):

```csv
date,your_reference,amount,status,currency
2024-03-15,bank_txn_123,5000,captured,EUR
2024-03-15,bank_txn_124,7500,captured,EUR
```

Upload endpoint:

```
POST /v1/bank/reconciliation/upload
```

## Best Practices

- Run reconciliation daily
- Investigate discrepancies immediately
- Maintain audit trails
- Automate where possible
- Keep reconciliation reports for 7 years
