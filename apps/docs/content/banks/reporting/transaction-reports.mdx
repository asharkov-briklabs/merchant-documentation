## Overview

Transaction reports provide comprehensive data on all payment transactions processed through your bank.

## Transaction Report API

```
GET /v1/bank/reports/transactions
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `date_from` | string | Start date (YYYY-MM-DD) |
| `date_to` | string | End date (YYYY-MM-DD) |
| `status` | string | Filter by status |
| `merchant_id` | string | Filter by merchant |
| `format` | string | Report format (csv, json, pdf) |

### Example Request

```bash
curl https://api.vinr.com/v1/bank/reports/transactions \
  -u bk_live_YOUR_KEY:YOUR_SECRET \
  -d date_from=2024-03-01 \
  -d date_to=2024-03-31 \
  -d format=csv
```

## Report Fields

| Field | Description |
|-------|-------------|
| `transaction_id` | Unique transaction identifier |
| `merchant_id` | Merchant identifier |
| `authorization_id` | Authorization identifier |
| `timestamp` | Transaction timestamp |
| `amount` | Transaction amount |
| `currency` | Currency code |
| `status` | Transaction status |
| `payment_method` | Payment method used |
| `card_last4` | Last 4 digits of card |
| `authorization_code` | Bank authorization code |
| `processor_response` | Processor response code |
| `fee_amount` | Processing fee |
| `net_amount` | Net amount after fees |

## Transaction Statuses

- `authorized` - Payment authorized
- `captured` - Payment captured
- `voided` - Authorization voided
- `refunded` - Payment refunded
- `declined` - Payment declined
- `failed` - Processing failed

## Filtering Options

### By Status

```bash
?status=captured,refunded
```

### By Merchant

```bash
?merchant_id=merch_123
```

### By Amount Range

```bash
?amount_min=1000&amount_max=10000
```

### By Payment Method

```bash
?payment_method=card
```

## Export Limits

- **CSV**: Up to 100,000 transactions
- **JSON**: Up to 50,000 transactions
- **PDF**: Up to 10,000 transactions

For larger datasets, use date range filtering or contact support.

## Scheduled Reports

Configure automatic daily transaction reports:

```
POST /v1/bank/scheduled-reports
```

```json
{
  "report_type": "transactions",
  "schedule": "daily",
  "time": "06:00",
  "timezone": "Europe/Sofia",
  "format": "csv",
  "delivery_method": "email",
  "recipients": ["finance@your-bank.com"]
}
```
