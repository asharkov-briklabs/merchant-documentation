The balance object shows the funds currently held in your VINR account, split into what is
immediately available for payouts and what is still pending settlement. The balance updates
automatically as payments are captured and payouts are initiated.

</Callout>

## The balance object

<Attributes>
  <Attribute name="available" type="array">
    Funds that can be paid out immediately. Each entry represents a currency bucket.
    <Attributes>
      <Attribute name="amount" type="integer">Available amount in the smallest currency unit (e.g. cents).</Attribute>
      <Attribute name="currency" type="string">Three-letter ISO currency code, e.g. `EUR`.</Attribute>
    </Attributes>
  </Attribute>
  <Attribute name="pending" type="array">
    Funds that have been received but are not yet available for payout (e.g. awaiting settlement).
    Each entry represents a currency bucket.
    <Attributes>
      <Attribute name="amount" type="integer">Pending amount in the smallest currency unit (e.g. cents).</Attribute>
      <Attribute name="currency" type="string">Three-letter ISO currency code, e.g. `EUR`.</Attribute>
    </Attributes>
  </Attribute>
</Attributes>

## Retrieve the balance

The balance is a singleton — there is no ID and no list endpoint. A single GET returns the full
breakdown across all currencies.

<ApiExample
  id="retrieve-balance"
  title="Retrieve the balance"
  method="GET"
  path="/v1/balance"
  request={{
    curl: `curl https://api.vinr.com/v1/balance \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const balance = await vinr.balance.retrieve();`,
    python: `import vinr

balance = vinr.Balance.retrieve()`,
    ruby: `balance = Vinr::Balance.retrieve`,
  }}
  response={`{
  "available": [
    { "amount": 428500, "currency": "EUR" },
    { "amount": 12000, "currency": "USD" }
  ],
  "pending": [
    { "amount": 95000, "currency": "EUR" }
  ]
}`}
/>
