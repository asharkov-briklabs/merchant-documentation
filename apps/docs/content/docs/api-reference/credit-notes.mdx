A credit note adjusts a finalized [invoice](/docs/api-reference/invoices) — for example when a
customer was overcharged or a partial refund is due. Credit notes reduce the invoice's amount due
without modifying the original invoice.

## The credit note object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the credit note, e.g. `cn_6Dp3fQwH`.
  </Attribute>
  <Attribute name="invoice" type="string" expandable>
    The ID of the invoice this credit note adjusts, e.g. `inv_1Ab5cDe6`. Expand to retrieve the
    full invoice object.
  </Attribute>
  <Attribute name="amount" type="integer">
    The credit amount in the smallest currency unit, e.g. `1500` for €15.00.
  </Attribute>
  <Attribute name="currency" type="string">
    Three-letter ISO currency code matching the invoice, e.g. `EUR`.
  </Attribute>
  <Attribute name="status" type="enum">
    Current state of the credit note: `issued` or `void`.
  </Attribute>
  <Attribute name="reason" type="enum">
    Why the credit was issued: `duplicate`, `fraudulent`, `order_change`, or `product_unsatisfactory`.
  </Attribute>
  <Attribute name="memo" type="string">
    Optional free-text note shown on the credit note PDF.
  </Attribute>
  <Attribute name="created" type="integer">
    Unix timestamp of when the credit note was created, e.g. `1716300000`.
  </Attribute>
</Attributes>

## Create a credit note

Pass the `invoice` ID, the `amount` to credit, and a `reason`. The credit note is immediately
issued and the invoice's amount due is reduced.

<ApiExample
  id="create-credit-note"
  title="Create a credit note"
  method="POST"
  path="/v1/credit-notes"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/credit-notes \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d invoice=inv_1Ab5cDe6 \\
  -d amount=1500 \\
  -d reason=order_change \\
  -d memo="Partial refund for unused period"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const creditNote = await vinr.creditNotes.create({
  invoice: 'inv_1Ab5cDe6',
  amount: 1500,
  reason: 'order_change',
  memo: 'Partial refund for unused period',
});`,
    python: `import vinr

credit_note = vinr.CreditNote.create(
    invoice="inv_1Ab5cDe6",
    amount=1500,
    reason="order_change",
    memo="Partial refund for unused period",
)`,
    ruby: `credit_note = Vinr::CreditNote.create(
  invoice: 'inv_1Ab5cDe6',
  amount: 1500,
  reason: 'order_change',
  memo: 'Partial refund for unused period',
)`,
  }}
  response={`{
  "id": "cn_6Dp3fQwH",
  "invoice": "inv_1Ab5cDe6",
  "amount": 1500,
  "currency": "EUR",
  "status": "issued",
  "reason": "order_change",
  "memo": "Partial refund for unused period",
  "created": 1716300000
}`}
/>

## Void a credit note

Voiding moves the credit note to `void` status and reverses its effect on the invoice's amount due.
Only `issued` credit notes can be voided.

<ApiExample
  id="void-credit-note"
  title="Void a credit note"
  method="POST"
  path="/v1/credit-notes/{id}/void"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/credit-notes/cn_6Dp3fQwH/void \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const creditNote = await vinr.creditNotes.void('cn_6Dp3fQwH');`,
