An earning rule defines how customers accumulate points in response to platform events. The most
common rule awards one point per unit of currency spent when a payment succeeds.

</Callout>

## The earning rule object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the earning rule, e.g. `er_2Gb7wJ`.
  </Attribute>
  <Attribute name="name" type="string">
    Human-readable label for the rule, e.g. `1 point per €1 spent`.
  </Attribute>
  <Attribute name="event" type="string">
    The platform event that triggers point accrual, e.g. `payment.succeeded`.
  </Attribute>
  <Attribute name="points_per_unit" type="integer">
    Number of points awarded for each qualifying unit of the triggering event.
  </Attribute>
  <Attribute name="unit_value" type="integer">
    The size of one unit in the smallest currency denomination (e.g. `100` = 100 cents = €1).
    Points are awarded in proportion to `amount / unit_value`.
  </Attribute>
  <Attribute name="active" type="boolean">
    Whether the rule is currently applied when the trigger event fires.
  </Attribute>
  <Attribute name="created" type="integer">
    Unix timestamp of when the earning rule was created.
  </Attribute>
</Attributes>

## Create an earning rule

Define a new rule. Rules take effect immediately for subsequent trigger events once `active` is set
to `true`.

<ApiExample
  id="create-earning-rule"
  title="Create an earning rule"
  method="POST"
  path="/v1/earning-rules"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/earning-rules \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d name="1 point per €1 spent" \\
  -d event=payment.succeeded \\
  -d points_per_unit=1 \\
  -d unit_value=100`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const rule = await vinr.earningRules.create({
  name: '1 point per €1 spent',
  event: 'payment.succeeded',
  points_per_unit: 1,
  unit_value: 100,
});`,
    python: `import vinr

rule = vinr.EarningRule.create(
    name="1 point per €1 spent",
    event="payment.succeeded",
    points_per_unit=1,
    unit_value=100,
)`,
    ruby: `rule = Vinr::EarningRule.create(
  name: '1 point per €1 spent',
  event: 'payment.succeeded',
  points_per_unit: 1,
  unit_value: 100,
)`,
  }}
  response={`{
  "id": "er_2Gb7wJ",
  "name": "1 point per €1 spent",
  "event": "payment.succeeded",
  "points_per_unit": 1,
  "unit_value": 100,
  "active": true,
  "created": 1716300000
}`}
/>

## Update an earning rule

## Delete an earning rule

Permanently deletes an earning rule. Existing points transactions created by this rule are not
affected.

## List earning rules

Returns a paginated list of earning rules. Pass `active=true` to return only currently live rules.

| Parameter | Type | Description |
|---|---|---|
| `active` | boolean | Filter by active status. Omit to return all rules. |
| `limit` | integer | Number of results to return. Default `10`, max `100`. |

<ApiExample
  id="list-earning-rules"
  title="List earning rules"
  method="GET"
  path="/v1/earning-rules"
  request={{
    curl: `curl "https://api.vinr.com/v1/earning-rules?active=true&limit=10" \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const rules = await vinr.earningRules.list({
  active: true,
  limit: 10,
});`,
    python: `import vinr

rules = vinr.EarningRule.list(

  active: true,
  limit: 10,
