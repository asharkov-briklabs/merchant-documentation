An event is created whenever something notable changes in your VINR account — a payment succeeds, an
invoice is paid, a subscription renews. Events are read-only; use
[webhook endpoints](/docs/api-reference/webhook-endpoints) to receive them in real time rather than
polling this API.

## The event object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the event, e.g. `evt_9Bz1kWpA`.
  </Attribute>
  <Attribute name="type" type="string">
    The event type, e.g. `payment.succeeded` or `invoice.paid`. Used as the routing key in webhook
    endpoint subscriptions.
  </Attribute>
  <Attribute name="data" type="object">
    Container for the resource snapshot at the time the event was created.
    <Attributes>
      <Attribute name="object" type="object">
        A full snapshot of the affected resource (e.g. the payment object). The shape matches the
        resource's normal retrieve response.
      </Attribute>
    </Attributes>
  </Attribute>
  <Attribute name="created" type="timestamp">
    Unix timestamp of when the event was created.
  </Attribute>
</Attributes>

## Retrieve an event

<ApiExample
  id="retrieve-event"
  title="Retrieve an event"
  method="GET"
  path="/v1/events/{id}"
  request={{
    curl: `curl https://api.vinr.com/v1/events/evt_9Bz1kWpA \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const event = await vinr.events.retrieve('evt_9Bz1kWpA');`,
    python: `import vinr

event = vinr.Event.retrieve("evt_9Bz1kWpA")`,
    ruby: `event = Vinr::Event.retrieve("evt_9Bz1kWpA")`,
  }}
  response={`{
  "id": "evt_9Bz1kWpA",
  "type": "payment.succeeded",
  "data": {
    "object": {
      "id": "pay_3Nx8a2Lk",
      "amount": 5000,
      "currency": "EUR",
      "status": "succeeded",
      "customer": "cust_8aZ2",
      "created": 1716300000
    }
  },
  "created": 1716300001
}`}
/>

## List events

Returns a list of events, optionally filtered by type or creation date. Results are sorted newest
first. Use `created.gte` to page forward from a known timestamp rather than polling for the latest.

<ApiExample
  id="list-events"
  title="List events"
  method="GET"
  path="/v1/events"
  request={{
    curl: `curl "https://api.vinr.com/v1/events?type=payment.succeeded&created.gte=1716300000&limit=5" \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const events = await vinr.events.list({
  type: 'payment.succeeded',
  'created.gte': 1716300000,
  limit: 5,
});`,
    python: `import vinr

events = vinr.Event.list(
    type="payment.succeeded",
    created={"gte": 1716300000},
    limit=5,
)`,
    ruby: `events = Vinr::Event.list(
  type: 'payment.succeeded',
  created: { gte: 1716300000 },
  limit: 5,
)`,
  }}
  response={`{
  "object": "list",
  "data": [
    {
      "id": "evt_9Bz1kWpA",
      "type": "payment.succeeded",
      "data": {
        "object": {
          "id": "pay_3Nx8a2Lk",
          "amount": 5000,
          "currency": "EUR",
          "status": "succeeded"
        }
      },
      "created": 1716300001
    }
  ],
  "has_more": false
}`}
/>
