A payout moves funds from your VINR balance to your connected bank account. VINR calculates the
available balance from captured payments minus fees, and you can trigger a payout manually or let
VINR schedule them automatically.

## The payout object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the payout, e.g. `po_7Kx3mBqR`.
  </Attribute>
  <Attribute name="amount" type="integer">
    Amount to be transferred to your bank account, in the smallest currency unit (e.g. cents).
  </Attribute>
  <Attribute name="currency" type="string">
    Three-letter ISO currency code, e.g. `EUR`.
  </Attribute>
  <Attribute name="status" type="enum">
    One of `pending`, `paid`, `failed`, or `canceled`.
  </Attribute>
  <Attribute name="arrival_date" type="timestamp">
    Unix timestamp for the estimated date the payout will arrive in the bank account.
  </Attribute>
  <Attribute name="bank_account" type="object">
    Snapshot of the destination bank account.
    <Attributes>
      <Attribute name="last4" type="string">Last four digits of the account number.</Attribute>
      <Attribute name="bank_name" type="string">Name of the receiving bank, e.g. `Deutsche Bank`.</Attribute>
    </Attributes>
  </Attribute>
  <Attribute name="created" type="timestamp">
    Unix timestamp of when the payout was created.
  </Attribute>
</Attributes>

## Create a payout

Specify an amount and currency to initiate an immediate transfer from your VINR balance to your bank
account. The payout starts in `pending` and transitions to `paid` once the bank confirms receipt.

<ApiExample
  id="create-payout"
  title="Create a payout"
  method="POST"
  path="/v1/payouts"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/payouts \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d amount=100000 \\
  -d currency=EUR`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const payout = await vinr.payouts.create({
  amount: 100000,
  currency: 'EUR',
});`,
    python: `import vinr

payout = vinr.Payout.create(
    amount=100000,
    currency="EUR",
)`,
    ruby: `payout = Vinr::Payout.create(
  amount: 100000,
  currency: 'EUR',
)`,
  }}
  response={`{
  "id": "po_7Kx3mBqR",
  "amount": 100000,
  "currency": "EUR",
  "status": "pending",
  "arrival_date": 1716556800,
  "bank_account": {
    "last4": "4242",
    "bank_name": "Deutsche Bank"
  },
  "created": 1716300000
}`}
/>

## Update a payout

Update mutable metadata on a payout. Only the `metadata` field can be changed after creation.

<ApiExample
  id="update-payout"
  title="Update a payout"
  method="POST"
  path="/v1/payouts/{id}"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/payouts/po_7Kx3mBqR \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d "metadata[order_id]=ord_001"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const payout = await vinr.payouts.update('po_7Kx3mBqR', {
  metadata: { order_id: 'ord_001' },
});`,
    python: `import vinr

payout = vinr.Payout.modify(
    "po_7Kx3mBqR",
    metadata={"order_id": "ord_001"},
)`,
    ruby: `payout = Vinr::Payout.update(
  "po_7Kx3mBqR",
  metadata: { order_id: 'ord_001' },
)`,
  }}
  response={`{
  "id": "po_7Kx3mBqR",
  "amount": 100000,
  "currency": "EUR",
  "status": "pending",
  "arrival_date": 1716556800,
  "bank_account": {
    "last4": "4242",
    "bank_name": "Deutsche Bank"
  },
  "metadata": {
    "order_id": "ord_001"

/>

## Cancel a payout

A payout can only be canceled while its status is `pending`. Once the bank has begun processing the
transfer, cancellation is no longer possible.

<ApiExample
  id="cancel-payout"
  title="Cancel a payout"
  method="POST"
  path="/v1/payouts/{id}/cancel"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/payouts/po_7Kx3mBqR/cancel \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const payout = await vinr.payouts.cancel('po_7Kx3mBqR');`,
    python: `import vinr

payout = vinr.Payout.cancel("po_7Kx3mBqR")`,
    ruby: `payout = Vinr::Payout.cancel("po_7Kx3mBqR")`,
  }}
  response={`{
  "id": "po_7Kx3mBqR",

  "status": "canceled",

    "last4": "4242",

## List payouts

Returns a list of payouts, optionally filtered by status. Results are sorted by creation date,
newest first.

<ApiExample
  id="list-payouts"
  title="List payouts"
  method="GET"
  path="/v1/payouts"
  request={{
    curl: `curl "https://api.vinr.com/v1/payouts?status=paid&limit=3" \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const payouts = await vinr.payouts.list({
  status: 'paid',
  limit: 3,
});`,
    python: `import vinr

payouts = vinr.Payout.list(
    status="paid",
    limit=3,
)`,
    ruby: `payouts = Vinr::Payout.list(
  status: 'paid',
  limit: 3,
)`,
  }}
  response={`{
  "object": "list",
  "data": [
    {
      "id": "po_7Kx3mBqR",
      "amount": 100000,
      "currency": "EUR",
      "status": "paid",
      "arrival_date": 1716556800,
      "created": 1716300000
    }
  ],
  "has_more": false
}`}
/>
