A price defines the billing amount and interval for a [product](/docs/api-reference/products). One
product can have many prices — for example, a monthly and an annual option for the same plan.

</Callout>

## The price object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the price, e.g. `price_9Rz1wBqT`.
  </Attribute>
  <Attribute name="product" type="string" expandable>
    The ID of the product this price belongs to, e.g. `prod_7Kc4mNpQ`. Expand to retrieve the full
    product object.
  </Attribute>
  <Attribute name="unit_amount" type="integer">
    The unit amount in the smallest currency unit (e.g. cents), e.g. `2900` for €29.00.
  </Attribute>
  <Attribute name="currency" type="string">
    Three-letter ISO currency code, e.g. `EUR`.
  </Attribute>
  <Attribute name="recurring" type="object">
    Billing frequency for subscription prices.
    <Attributes>
      <Attribute name="interval" type="enum">
        Billing interval: `month` or `year`.
      </Attribute>
      <Attribute name="interval_count" type="integer">
        Number of intervals between billings. `1` means every interval, `3` means every 3 months, etc.
      </Attribute>
    </Attributes>
  </Attribute>
  <Attribute name="active" type="boolean">
    Whether the price can be used for new purchases. Defaults to `true`.
  </Attribute>
  <Attribute name="nickname" type="string">
    An optional internal label for the price, e.g. `"Monthly (legacy)"`.
  </Attribute>
  <Attribute name="created" type="integer">
    Unix timestamp of when the price was created, e.g. `1716300000`.
  </Attribute>
</Attributes>

## Create a price

Pass a `product`, `unit_amount`, `currency`, and optional `recurring` object to create a price.
Omit `recurring` for one-time prices.

<ApiExample
  id="create-price"
  title="Create a price"
  method="POST"
  path="/v1/prices"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/prices \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d product=prod_7Kc4mNpQ \\
  -d unit_amount=2900 \\
  -d currency=EUR \\
  -d "recurring[interval]=month"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const price = await vinr.prices.create({
  product: 'prod_7Kc4mNpQ',
  unit_amount: 2900,
  currency: 'EUR',
  recurring: { interval: 'month' },
});`,
    python: `import vinr

price = vinr.Price.create(
    product="prod_7Kc4mNpQ",
    unit_amount=2900,
    currency="EUR",
    recurring={"interval": "month"},
)`,
    ruby: `price = Vinr::Price.create(
  product: 'prod_7Kc4mNpQ',
  unit_amount: 2900,
  currency: 'EUR',
  recurring: { interval: 'month' },
)`,
  }}
  response={`{
  "id": "price_9Rz1wBqT",
  "product": "prod_7Kc4mNpQ",
  "unit_amount": 2900,
  "currency": "EUR",
  "recurring": {
    "interval": "month",
    "interval_count": 1
  },
  "active": true,
  "nickname": null,
  "created": 1716300000
}`}
/>

## Update a price

Only `active` and `nickname` can be updated after creation. To change the amount, create a new
price and archive the old one by setting `active: false`.

<ApiExample
  id="update-price"
  title="Update a price"
  method="POST"
  path="/v1/prices/{id}"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/prices/price_9Rz1wBqT \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d nickname="Monthly standard" \\
  -d active=true`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const price = await vinr.prices.update('price_9Rz1wBqT', {
  nickname: 'Monthly standard',
  active: true,
});`,
    python: `import vinr

price = vinr.Price.modify(
    "price_9Rz1wBqT",
    nickname="Monthly standard",
    active=True,
)`,
    ruby: `price = Vinr::Price.update(
  'price_9Rz1wBqT',
  nickname: 'Monthly standard',
  active: true,
)`,
  }}
  response={`{
  "id": "price_9Rz1wBqT",
  "product": "prod_7Kc4mNpQ",
  "unit_amount": 2900,
  "currency": "EUR",
  "recurring": {
    "interval": "month",
    "interval_count": 1
  },
  "active": true,
  "nickname": "Monthly standard",
  "created": 1716300000
}`}
/>

## List prices

Returns a paginated list of prices. Filter by `product` to list all prices for a given product.

<ApiExample
  id="list-prices"
  title="List prices"
  method="GET"
  path="/v1/prices"
  request={{
    curl: `curl "https://api.vinr.com/v1/prices?product=prod_7Kc4mNpQ&active=true&limit=10" \\
  -H "X-Api-Key: $VINR_SECRET_KEY"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const prices = await vinr.prices.list({
  product: 'prod_7Kc4mNpQ',
  active: true,
  limit: 10,
});`,
    python: `import vinr

prices = vinr.Price.list(
    product="prod_7Kc4mNpQ",
    active=True,
    limit=10,
)`,
    ruby: `prices = Vinr::Price.list(
  product: 'prod_7Kc4mNpQ',
  active: true,
  limit: 10,
)`,
  }}
  response={`{
  "object": "list",
  "data": [
    {
      "id": "price_9Rz1wBqT",
      "product": "prod_7Kc4mNpQ",
      "unit_amount": 2900,
      "currency": "EUR",
      "recurring": {
        "interval": "month",
        "interval_count": 1
      },
      "active": true,
      "nickname": "Monthly standard",
      "created": 1716300000
    }
  ],
  "has_more": false
}`}
/>
