A quote presents a pricing proposal to a prospective customer before they commit to a subscription.
Once accepted, VINR automatically converts the quote into a live subscription.

<Callout type="info">
**Illustrative content.** Hand-authored to demonstrate the Standard/Advanced pattern; the production
page will be generated from the VINR OpenAPI spec (roadmap item #1). Field names are representative.
</Callout>

## The quote object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the quote, e.g. `qt_5Bw2xNjR`.
  </Attribute>
  <Attribute name="customer" type="string" expandable>
    The ID of the customer this quote is for, e.g. `cust_8aZ2`. Expand to retrieve the full
    customer object.
  </Attribute>
  <Attribute name="status" type="enum">
    Quote lifecycle state: `draft`, `open`, `accepted`, or `canceled`.
  </Attribute>
  <Attribute name="amount_total" type="integer">
    Total amount across all line items, in the smallest currency unit.
  </Attribute>
  <Attribute name="currency" type="string">
    Three-letter ISO currency code, e.g. `EUR`.
  </Attribute>
  <Attribute name="expires_at" type="integer">
    Unix timestamp after which the quote can no longer be accepted.
  </Attribute>
  <Attribute name="line_items" type="array">
    The list of products and prices included in the quote. Each item has `price`, `quantity`, and
    `amount_subtotal`.
  </Attribute>
  <Attribute name="created" type="integer">
    Unix timestamp of when the quote was created, e.g. `1716300000`.
  </Attribute>
</Attributes>

## Create a quote

Create a quote in `draft` status. Add `line_items` referencing existing prices.

<ApiExample
  id="create-quote"
  title="Create a quote"
  method="POST"
  path="/v1/quotes"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/quotes \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d customer=cust_8aZ2 \\
  -d "line_items[0][price]=price_9Rz1wBqT" \\
  -d "line_items[0][quantity]=1"`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const quote = await vinr.quotes.create({
  customer: 'cust_8aZ2',
  line_items: [{ price: 'price_9Rz1wBqT', quantity: 1 }],
});`,
    python: `import vinr

quote = vinr.Quote.create(
    customer="cust_8aZ2",
    line_items=[{"price": "price_9Rz1wBqT", "quantity": 1}],
)`,
    ruby: `quote = Vinr::Quote.create(
  customer: 'cust_8aZ2',
  line_items: [{ price: 'price_9Rz1wBqT', quantity: 1 }],
)`,
  }}
  response={`{
  "id": "qt_5Bw2xNjR",
  "customer": "cust_8aZ2",
  "status": "draft",
  "amount_total": 2900,
  "currency": "EUR",
  "expires_at": null,
  "line_items": [
    {
      "price": "price_9Rz1wBqT",
      "quantity": 1,
      "amount_subtotal": 2900
    }
  ],
  "created": 1716300000
}`}
/>

## Update a quote

Update a `draft` or `open` quote. Only `description` and `expires_at` can be changed.

<ApiExample
  id="update-quote"
  title="Update a quote"
  method="POST"
  path="/v1/quotes/{id}"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/quotes/qt_5Bw2xNjR \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d description="Special pricing for Q3" \\
  -d expires_at=1718892000`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const quote = await vinr.quotes.update('qt_5Bw2xNjR', {

  expires_at: 1718892000,
});`,

const quote = await vinr.quotes.finalize('qt_5Bw2xNjR');`,
    python: `import vinr

  "currency": "EUR",

}`}
/>
