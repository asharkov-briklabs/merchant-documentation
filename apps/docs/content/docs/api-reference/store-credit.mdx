Store credit is a balance of credit applied to a customer's future purchases. When a customer has
available store credit, it can be automatically applied at checkout to reduce the amount charged to
their payment method.

## The store credit object

<Attributes>
  <Attribute name="id" type="string">
    Unique identifier for the store credit record, e.g. `sc_4Bk9mQ`.
  </Attribute>
  <Attribute name="customer" type="object" expandable>
    The customer this store credit belongs to. Expand to retrieve the full customer object.
    <Attributes>
      <Attribute name="id" type="string">Customer identifier, e.g. `cust_8aZ2`.</Attribute>
      <Attribute name="email" type="string">Email address on the customer record.</Attribute>
    </Attributes>
  </Attribute>
  <Attribute name="amount" type="integer">
    Original credit amount issued, in the smallest currency unit (e.g. cents).
  </Attribute>
  <Attribute name="currency" type="string">
    Three-letter [ISO currency code](/docs/payments/payment-methods), e.g. `USD`.
  </Attribute>
  <Attribute name="balance_remaining" type="integer">
    Amount of credit still available to redeem, in the smallest currency unit.
  </Attribute>
  <Attribute name="expires_at" type="integer">
    Unix timestamp at which this credit expires and can no longer be redeemed, or `null` if it does
    not expire.
  </Attribute>
  <Attribute name="created" type="integer">
    Unix timestamp when this store credit record was created.
  </Attribute>
</Attributes>

## Create store credit

Issue store credit to a customer. Specify an amount, currency, and optionally an expiry date.

<ApiExample

  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d customer=cust_8aZ2 \\
  -d amount=1000 \\
  -d currency=USD \\
  -d expires_at=1748736000`,

## Update store credit

Update the expiry date on an existing store credit record. The `balance_remaining` is read-only and
adjusted automatically as the credit is applied to purchases.

| Parameter | Type | Description |
|---|---|---|
| `expires_at` | integer | New Unix timestamp for expiry. Set to `null` to remove expiry. |

<ApiExample
  id="update-store-credit"
  title="Update store credit"
  method="POST"
  path="/v1/store-credit/{id}"
  request={{
    curl: `curl -X POST https://api.vinr.com/v1/store-credit/sc_4Bk9mQ \\
  -H "X-Api-Key: $VINR_SECRET_KEY" \\
  -d expires_at=1751328000`,
    node: `import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

    python: `import vinr

credit = vinr.StoreCredit.modify(

    expires_at=1751328000,
)`,
    ruby: `credit = Vinr::StoreCredit.update(

  expires_at: 1751328000,

  response={`{

## List store credit

Returns a paginated list of store credit records. Use the `customer` filter to scope results to a
single customer.

| Parameter | Type | Description |
|---|---|---|
| `customer` | string | Filter records by customer ID. |
| `limit` | integer | Number of results to return. Default `10`, max `100`. |
