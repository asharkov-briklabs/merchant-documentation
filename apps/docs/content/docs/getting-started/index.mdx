## Overview

Get up and running with VINR in minutes. This section covers account setup, your first API call, and understanding the basic payment flow.

## Prerequisites

Before you begin, ensure you have:

- A VINR merchant account (contact sales@vinr.com)
- API credentials (available in your merchant dashboard)
- A development environment with HTTPS support for webhooks
