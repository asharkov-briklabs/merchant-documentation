## What is VINR?

VINR is a last-mile multi-rail payment infrastructure for modern businesses. Banks, cards, stablecoins, and local payment methods — all through one checkout that works everywhere.

## Who is this documentation for?

This documentation serves all merchant stakeholders:

- **Developers** — API references, SDKs, integration guides, webhooks
- **Finance Managers** — Settlement, reconciliation, fee structures
- **Operations Teams** — Dashboard guides, monitoring, alerts
- **Compliance Officers** — KYC/AML, PCI DSS, regulatory requirements
- **Business Owners** — Platform overview, pricing, strategic decisions
