Learn about product codes for cards.

Product codes exist as a way to identify the specific program or product associated with a credit card.

## Retrieving product codes

When using the VINR Payments API, the product code is stored on the `PaymentMethod` object in the `brand_product` field within the `card` hash. After successfully confirming a payment, the `brand_product` field is also present in `payment_method_details.card` on the corresponding charge object in the API response.

The `brand_product` field might be `null` if the product code hasn't been collected yet (for example, when creating a card) or the product codes for the particular card network aren't supported. VINR currently supports Visa and Mastercard product codes only.

```typescript
import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const paymentMethod = await vinr.paymentMethods.retrieve('pm_ABC123');
console.log(paymentMethod.card?.brandProduct); // e.g. "I" (Visa Infinite)
```
