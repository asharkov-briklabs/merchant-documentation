Product codes identify the specific program or product associated with a card — for example, whether a Visa card is a Classic, Platinum, or Infinite product. VINR currently supports product codes for Visa and Mastercard only.

## Retrieving product codes

When using the VINR Payments API, the product code is stored on the `PaymentMethod` object in the `brand_product` field within the `card` hash. After a payment is confirmed, `brand_product` is also present in `payment_method_details.card` on the corresponding charge object.

```typescript
import { Vinr } from '@vinr/sdk';

const vinr = new Vinr({ secretKey: process.env.VINR_SECRET_KEY });

const paymentMethod = await vinr.paymentMethods.retrieve('pm_ABC123');
console.log(paymentMethod.card?.brandProduct); // e.g. "I" (Visa Infinite)
```

The `brand_product` field may be `null` if:

- The product code has not yet been collected (for example, immediately after card creation before confirmation).
- The card network for that card does not support product codes.
