## Overview

Export your payment data for use in external systems and tools.

## Export Formats

- **CSV** - For spreadsheet applications
- **JSON** - For programmatic access
- **PDF** - For reports and documentation
- **Excel** - For advanced analysis

## Exporting Data

### Manual Export

1. Navigate to the data you want to export
2. Click the **Export** button
3. Select your desired format
4. Download the file

### API Export

Use the Vinr API to programmatically export data:

```javascript
const export = await vinr.exports.create({
  type: 'transactions',
  format: 'csv',
  date_from: '2024-01-01',
  date_to: '2024-12-31',
});
```

## Export Limits

- **CSV/Excel**: Up to 100,000 rows per export
- **JSON**: Up to 10,000 records per export
- **PDF**: Up to 1,000 rows per export
