# Get Started with Vinr

Welcome! This guide will help you set up your Vinr account and start accepting payments.

## What You'll Learn

In this section, you'll learn how to:

1. **Set up your account** - Create and configure your Vinr merchant account
2. **Get API credentials** - Generate API keys for your integration
3. **Accept your first payment** - Complete a test transaction
4. **Go live** - Move from test mode to production

## Prerequisites

Before you begin, make sure you have:

- ✅ A registered business in Bulgaria, Romania, Greece, or Poland
- ✅ Business bank account
- ✅ Basic technical knowledge (for API integration)
- ✅ Valid business documentation
