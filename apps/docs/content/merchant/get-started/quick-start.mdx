# Quick Start Guide

This guide will walk you through creating your first payment with Vinr. By the end, you'll have processed a test transaction and be ready to integrate Vinr into your application.

<Callout type="info">
**Estimated time:** 15 minutes
</Callout>

## Step 1: Create Your Account

1. Go to [dashboard.vinr.com](https://dashboard.vinr.com)
2. Click "Sign Up" and complete the registration
3. Verify your email address
4. You'll be automatically logged into test mode

## Step 2: Get Your API Keys

1. Navigate to **Settings** → **API Keys** in the dashboard
2. Click "Create New Key"
3. Copy your **Publishable Key** and **Secret Key**

<Callout type="warning">
**Keep your Secret Key secure!** Never expose it in client-side code or public repositories.
</Callout>

```bash
# Your keys will look like this:
VINR_PUBLISHABLE_KEY=pk_test_abc123...
VINR_SECRET_KEY=sk_test_xyz789...
```

## Step 3: Install the SDK

Choose your preferred language:

<Tabs items={['JavaScript', 'Python', 'PHP']}>
  <Tab value="JavaScript">
    ```bash
    npm install @vinr/node-sdk
    ```
  </Tab>
  
  <Tab value="Python">
    ```bash
    pip install vinr
    ```
  </Tab>
  
  <Tab value="PHP">
    ```bash
    composer require vinr/vinr-php
    ```
  </Tab>
</Tabs>

## Step 4: Initialize the Client

<Tabs items={['JavaScript', 'Python', 'PHP']}>
  <Tab value="JavaScript">
    ```javascript
    const Vinr = require('@vinr/node-sdk');
    
    const vinr = new Vinr({
      apiKey: process.env.VINR_SECRET_KEY,
      environment: 'test' // Use 'production' for live transactions
    });
    ```
  </Tab>
  
  <Tab value="Python">
    ```python
    import vinr
    
    vinr.api_key = os.environ.get('VINR_SECRET_KEY')
    vinr.environment = 'test'  # Use 'production' for live
    ```
  </Tab>
  
  <Tab value="PHP">
    ```php
    require_once('vendor/autoload.php');
    
    \Vinr\Vinr::setApiKey(getenv('VINR_SECRET_KEY'));
    \Vinr\Vinr::setEnvironment('test');
    ```
  </Tab>
</Tabs>

## Step 5: Create a Payment

<Tabs items={['JavaScript', 'Python', 'PHP']}>
  <Tab value="JavaScript">
    ```javascript
    const payment = await vinr.payments.create({
      amount: 1000, // Amount in smallest currency unit (cents)
      currency: 'BGN',
      customer: {
        email: 'customer@example.com',
        name: 'John Doe'
      },
      description: 'Order #1234'
    });
    
    console.log('Payment created:', payment.id);
    console.log('Payment URL:', payment.url);
    ```
  </Tab>
  
  <Tab value="Python">
    ```python
    payment = vinr.Payment.create(
        amount=1000,  # Amount in stotinki
        currency='BGN',
        customer={
            'email': 'customer@example.com',
            'name': 'John Doe'
        },
        description='Order #1234'
    )
    
    print(f'Payment created: {payment.id}')
    print(f'Payment URL: {payment.url}')
    ```
  </Tab>
  
  <Tab value="PHP">
    ```php
    $payment = \Vinr\Payment::create([
        'amount' => 1000, // Amount in stotinki
        'currency' => 'BGN',
        'customer' => [
            'email' => 'customer@example.com',
            'name' => 'John Doe'
        ],
        'description' => 'Order #1234'
    ]);
    
    echo 'Payment created: ' . $payment->id;
    echo 'Payment URL: ' . $payment->url;
    ```
  </Tab>
</Tabs>

## Step 6: Test the Payment

1. Open the `payment.url` in your browser
2. Use test card: `4242 4242 4242 4242`
3. Use any future expiry date (e.g., 12/25)
4. Use any 3-digit CVC (e.g., 123)
5. Click "Pay"

<Callout type="success">
**Success!** You've processed your first Vinr payment.
</Callout>

## Step 7: Verify the Payment

Check the payment status:

```javascript
const payment = await vinr.payments.retrieve(paymentId);
console.log('Status:', payment.status); // 'succeeded'
```

## Common Issues

<Accordion>
  <AccordionItem title="'Invalid API key' error">
    Make sure you're using your Secret Key (starts with `sk_test_`) and not your Publishable Key.
  </AccordionItem>
  
  <AccordionItem title="Payment is 'pending' instead of 'succeeded'">
    Some payment methods require additional steps. Check the `payment.next_action` field.
  </AccordionItem>
  
  <AccordionItem title="Can't find my API keys">
    Go to **Settings** → **API Keys** in your dashboard. Make sure you're in test mode.
  </AccordionItem>
</Accordion>
