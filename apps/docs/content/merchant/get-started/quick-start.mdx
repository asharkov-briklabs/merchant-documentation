# Quick Start Guide

This guide will walk you through creating your first payment with Vinr. By the end, you'll have processed a test transaction and be ready to integrate Vinr into your application.

## Step 1: Create Your Account

1. Go to dashboard.vinr.com
2. Click "Sign Up" and complete the registration
3. Verify your email address
4. You'll be automatically logged into test mode

## Step 2: Get Your API Keys

1. Navigate to **Settings** then **API Keys** in the dashboard
2. Click "Create New Key"
3. Copy your **Publishable Key** and **Secret Key**

> **Keep your Secret Key secure!** Never expose it in client-side code or public repositories.

```bash
# Your keys will look like this:
VINR_PUBLISHABLE_KEY=pk_test_abc123...
VINR_SECRET_KEY=sk_test_xyz789...
```

## Step 3: Install the SDK

```bash
npm install @vinr/node-sdk
```

## Step 4: Initialize the Client

```javascript
const Vinr = require('@vinr/node-sdk');

const vinr = new Vinr({
  apiKey: process.env.VINR_SECRET_KEY,
  environment: 'test'
});
```

## Step 5: Create a Payment

```javascript
const payment = await vinr.payments.create({
  amount: 1000,
  currency: 'BGN',
  customer: {
    email: 'customer@example.com',
    name: 'John Doe'
  },
  description: 'Order #1234'
});

console.log('Payment created:', payment.id);
console.log('Payment URL:', payment.url);
```

## Step 6: Test the Payment

1. Open the `payment.url` in your browser
2. Use test card: `4242 4242 4242 4242`
3. Use any future expiry date (e.g., 12/25)
4. Use any 3-digit CVC (e.g., 123)
5. Click "Pay"

## Test Cards

| Card Number | Description |
|---|---|
| 4242 4242 4242 4242 | Successful payment |
| 4000 0000 0000 0002 | Card declined |
| 4000 0000 0000 9995 | Insufficient funds |
