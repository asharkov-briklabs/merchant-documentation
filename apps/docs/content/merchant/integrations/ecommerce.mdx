## Overview

Connect Vinr with popular e-commerce platforms to accept payments seamlessly.

## WooCommerce

### Installation

1. Download the Vinr WooCommerce plugin
2. Upload to your WordPress plugins directory
3. Activate the plugin
4. Configure your API keys

### Configuration

Navigate to **WooCommerce** → **Settings** → **Payments** → **Vinr**:

- Enter your API keys
- Enable test mode (optional)
- Configure payment methods
- Customize payment page settings

## Shopify

### Installation

1. Visit the Shopify App Store
2. Search for "Vinr Payments"
3. Click **Add app**
4. Authorize the connection

### Configuration

- Set up payment methods
- Configure currency settings
- Enable automatic order fulfillment

## Magento

### Installation

```bash
composer require vinr/magento2-payment
bin/magento setup:upgrade
bin/magento cache:flush
```

### Configuration

Navigate to **Stores** → **Configuration** → **Sales** → **Payment Methods** → **Vinr**.

## PrestaShop

### Installation

1. Download the Vinr PrestaShop module
2. Upload via **Modules** → **Module Manager**
3. Install and configure
