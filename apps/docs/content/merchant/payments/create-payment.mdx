## Overview

This guide walks you through creating and processing a payment using Vinr's payment API.

## Prerequisites

Before you begin, ensure you have:

- A Vinr account with API keys
- Completed the [authentication setup](/merchant/get-started/authentication)
- Installed the Vinr SDK or can make HTTP requests

## Step 1: Create a Payment Intent

```javascript
const paymentIntent = await vinr.paymentIntents.create({
  amount: 5000, // 50.00 EUR in cents
  currency: 'EUR',
  payment_method_types: ['card'],
  description: 'Order #12345',
});
```

## Step 2: Collect Payment Details

Use Vinr's pre-built UI components or build your own payment form.

## Step 3: Confirm the Payment

```javascript
const result = await vinr.confirmPayment({
  payment_intent_id: paymentIntent.id,
  payment_method: paymentMethodId,
});
```
