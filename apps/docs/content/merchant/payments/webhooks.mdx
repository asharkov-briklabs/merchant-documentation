## Overview

Webhooks allow Vinr to notify your application when payment events occur.

## Setting Up Webhooks

1. Navigate to **Settings** → **Webhooks** in your dashboard
2. Click **Add Endpoint**
3. Enter your webhook URL
4. Select the events you want to receive

## Webhook Events

Common payment events:

- `payment_intent.succeeded` - Payment completed successfully
- `payment_intent.failed` - Payment failed
- `refund.created` - Refund was created
- `refund.completed` - Refund was completed

## Handling Webhooks

```javascript
app.post('/webhooks/vinr', async (req, res) => {
  const event = req.body;

  switch (event.type) {
    case 'payment_intent.succeeded':
      // Fulfill the order
      await fulfillOrder(event.data.object);
      break;
    case 'payment_intent.failed':
      // Notify customer
      await notifyCustomer(event.data.object);
      break;
  }

  res.json({received: true});
});
```

## Verifying Webhook Signatures

Always verify webhook signatures to ensure they came from Vinr:

```javascript
const signature = req.headers['vinr-signature'];
const isValid = vinr.webhooks.verify(req.body, signature);
```
