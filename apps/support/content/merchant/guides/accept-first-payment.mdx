## Overview

This guide shows you how to accept your first payment using Vinr's API.

**Time required**: 20-30 minutes  
**Prerequisites**: Vinr account with API keys

## Step 2: Create Payment Intent (Server-side)

Create a payment intent on your server:

```javascript
// server.js
const Vinr = require('@vinr/sdk');
const vinr = new Vinr(process.env.VINR_SECRET_KEY);

app.post('/create-payment-intent', async (req, res) => {
  try {
    const paymentIntent = await vinr.paymentIntents.create({
      amount: 2000, // €20.00 in cents
      currency: 'EUR',
      payment_method_types: ['card'],
      description: 'Test Payment',
    });

    res.json({
      clientSecret: paymentIntent.client_secret
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

## Step 4: Handle Payment Submission

```javascript
// checkout.js
const vinr = Vinr('pk_test_YOUR_PUBLISHABLE_KEY');
const elements = vinr.elements();
const cardElement = elements.create('card');
cardElement.mount('#card-element');

const form = document.getElementById('payment-form');
const errorMessage = document.getElementById('error-message');

form.addEventListener('submit', async (event) => {
  event.preventDefault();

  // Show loading state
  const submitButton = form.querySelector('button');
  submitButton.disabled = true;
  submitButton.textContent = 'Processing...';

  try {
    // Get client secret from server
    const response = await fetch('/create-payment-intent', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
    });
    const { clientSecret } = await response.json();

    // Confirm payment
    const { error, paymentIntent } = await vinr.confirmCardPayment(
      clientSecret,
      {
        payment_method: {
          card: cardElement,
          billing_details: {
            name: 'Customer Name',
          },
        },
      }
    );

    if (error) {
      // Show error to customer
      errorMessage.textContent = error.message;
      submitButton.disabled = false;
      submitButton.textContent = 'Pay Now';
    } else if (paymentIntent.status === 'succeeded') {
      // Payment succeeded!
      window.location.href = '/success';
    }
  } catch (error) {
    errorMessage.textContent = 'Payment failed. Please try again.';
    submitButton.disabled = false;
    submitButton.textContent = 'Pay Now';
  }
});
```

  }

  res.json({ received: true });

## Common Issues

### "Invalid API key" error

- Verify you're using the correct key
- Check for typos or extra spaces
- Ensure using test key in test mode

### Payment form not showing

- Check browser console for errors
- Verify Vinr.js script is loaded
- Ensure publishable key is correct

### Webhook not received

- Verify webhook URL is publicly accessible
- Check webhook logs in dashboard
- Ensure endpoint returns 200 status
