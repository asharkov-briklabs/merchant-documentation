## Login Issues

### Can't Log In

**Symptoms**:
- "Invalid email or password" error
- Login page keeps refreshing
- 2FA code not working

**Solutions**:

1. **Reset your password**:
   - Go to [vinr.com/login](https://vinr.com/login)
   - Click "Forgot Password"
   - Check email for reset link
   - Create new password

2. **Clear browser cache**:
   - Clear cookies and cache
   - Try incognito/private mode
   - Try different browser

3. **Check 2FA code**:
   - Ensure device time is correct
   - Generate new code
   - Use backup codes if available

4. **Account locked**:
   - Wait 30 minutes after multiple failed attempts
   - Contact support if still locked

### Email Not Recognized

**Cause**: Using wrong email address

**Solution**:
1. Try alternative email addresses
2. Check email typos
3. Contact support with business details

## Verification Issues

### Verification Pending

**Status**: Account verification in progress

**Timeline**:
- Standard: 1-2 business days
- With issues: 3-5 business days

**What to do**:
1. Check email for document requests
2. Ensure all documents are clear and valid
3. Contact support for status update

### Verification Rejected

**Common reasons**:
- Unclear documents
- Missing information
- Mismatched details
- Expired documents

**Solutions**:
1. Check email for rejection reason
2. Upload new/clearer documents
3. Ensure information matches exactly
4. Contact support for guidance

### Can't Upload Documents

**Solutions**:
1. **Check file requirements**:
   - Formats: PDF, JPG, PNG
   - Max size: 10MB per file
   - Clear and readable

2. **Try different browser/device**:
   - Use desktop instead of mobile
   - Try Chrome or Firefox
   - Disable browser extensions

3. **Compress large files**:
   - Use image compression tools
   - Convert to PDF if needed

## Dashboard Issues

### Dashboard Not Loading

**Solutions**:
1. **Check internet connection**
2. **Clear browser cache and cookies**
3. **Disable browser extensions**
4. **Try different browser**
5. **Check [status.vinr.com](https://status.vinr.com)**

### Data Not Updating

**Symptoms**:
- Old transaction data
- Stale balances
- Missing payments

**Solutions**:
1. Hard refresh page (Ctrl+Shift+R / Cmd+Shift+R)
2. Log out and log back in
3. Clear browser cache
4. Wait 5 minutes (data syncs periodically)

### Export Failing

**Error**: Can't download reports or exports

**Solutions**:
1. **Check file size**:
   - Large exports may time out
   - Reduce date range
   - Use API for large datasets

2. **Browser settings**:
   - Allow pop-ups for vinr.com
   - Check download location has space
   - Disable download managers

3. **Try different format**:
   - CSV instead of Excel
   - JSON for programmatic access

## Permission Issues

### Access Denied

**Error**: "You don't have permission to access this resource"

**Causes**:
- Insufficient user role
- Feature not in your plan
- Account suspended

**Solutions**:
1. **Check your role**:
   - Ask admin to grant permissions
   - Verify role requirements

2. **Upgrade plan** (if feature locked):
   - Go to **Settings** → **Billing**
   - Upgrade to required plan

3. **Account suspended**:
   - Check email for suspension notice
   - Contact support

### Can't Add Team Members

**Causes**:
- Not an admin
- Team limit reached
- Plan doesn't support multiple users

**Solutions**:
1. Verify you have admin role
2. Upgrade plan for more users
3. Remove inactive users first

## Payout Issues

### Missing Payout

**Causes**:
- Payout not due yet
- Bank details incorrect
- Account under review

**Solutions**:
1. **Check payout schedule**:
   - View **Settings** → **Payouts**
   - Verify expected payout date

2. **Verify bank details**:
   - Check account number
   - Verify bank routing number
   - Update if needed

3. **Check for holds**:
   - Review email for notices
   - Contact support for details

### Bank Verification Failed

**Solutions**:
1. **Re-verify bank account**:
   - Check for micro-deposit
   - Enter verification amounts
   - Allow 1-2 days for deposits

2. **Update bank details**:
   - Ensure all information is correct
   - Match business name exactly
   - Contact support if issues persist
