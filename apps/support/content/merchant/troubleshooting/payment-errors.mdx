## Declined Payments

### Card Declined

**Error**: `card_declined`

**Causes**:
- Insufficient funds
- Card issuer blocked transaction
- Daily spending limit reached

**Solutions**:
1. Ask customer to contact their bank
2. Try alternative payment method
3. Verify card details are correct

### Insufficient Funds

**Error**: `insufficient_funds`

**Solution**: Customer needs to use a different payment method or add funds to their account.

### Expired Card

**Error**: `expired_card`

**Solution**: Ask customer to provide updated card details.

### Invalid Card Number

**Error**: `invalid_card_number`

**Causes**:
- Typo in card number
- Invalid card format
- Test card used in live mode

**Solutions**:
1. Verify card number is entered correctly
2. Check for spaces or special characters
3. Ensure using correct environment (test vs live)

## 3D Secure Issues

### 3D Secure Failed

**Error**: `3ds_failed`

**Causes**:
- Customer cancelled authentication
- Wrong password entered
- Bank authentication timeout

**Solutions**:
1. Ask customer to retry payment
2. Ensure customer completes authentication
3. Contact card issuer if problem persists

### 3D Secure Timeout

**Error**: `3ds_timeout`

**Solution**: 
1. Ask customer to retry payment
2. Check customer's internet connection
3. Try alternative payment method

## Processing Errors

### Payment Timeout

**Error**: `payment_timeout`

**Causes**:
- Network connectivity issues
- Bank processing delays
- High transaction volume

**Solutions**:
1. Check payment status before retrying
2. Wait 60 seconds before retry
3. Verify network connectivity

### Processing Error

**Error**: `processing_error`

**Causes**:
- Temporary system issue
- Bank system unavailable
- Configuration error

**Solutions**:
1. Check [System Status](https://status.vinr.com)
2. Retry after 5 minutes
3. Contact support if error persists

### Duplicate Payment

**Error**: `duplicate_transaction`

**Cause**: Same payment submitted multiple times

**Solution**:
1. Use idempotency keys to prevent duplicates
2. Check if original payment succeeded
3. Don't retry immediately after success

## Amount Errors

### Amount Too Small

**Error**: `amount_too_small`

**Minimum amounts**:
- EUR: €0.50
- BGN: 1.00 BGN
- RON: 2.50 RON
- PLN: 2.00 PLN

**Solution**: Increase payment amount to meet minimum.

### Amount Too Large

**Error**: `amount_too_large`

**Maximum amounts**:
- Single transaction: €25,000
- Daily total: €100,000

**Solution**: 
1. Split into smaller transactions
2. Contact support for limit increase

## Refund Errors

### Refund Failed

**Error**: `refund_failed`

**Causes**:
- Original payment not settled
- Insufficient merchant balance
- Refund window expired

**Solutions**:
1. Wait for payment to settle (24-48 hours)
2. Verify merchant balance
3. Contact support for expired refunds

### Partial Refund Not Allowed

**Error**: `partial_refund_not_supported`

**Cause**: Payment method doesn't support partial refunds

**Solution**: Issue full refund only.

## Checking Error Details

View detailed error information:

```javascript
try {
  const payment = await vinr.payments.create({...});
} catch (error) {
  console.log('Error code:', error.code);
  console.log('Error message:', error.message);
  console.log('Decline code:', error.decline_code);
}
```
